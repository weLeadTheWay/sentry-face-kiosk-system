   • Read SECURITY_SUMMARY.md (security checklist)

2. PREPARE PRODUCTION ENVIRONMENT
   • Create production .env file (manually, NOT from git)
   • Generate APP_KEY: php artisan key:generate
   • Configure database credentials
   • Create strong SYNC_API_KEY (for AppSheet)

3. OBTAIN GOOGLE CREDENTIALS
   • Download service-account.json from Google Cloud Console
   • Place in credentials/service-account.json (local only)

   • Obtain Google Sheets spreadsheet ID
